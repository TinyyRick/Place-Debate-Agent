# 小程序 UI + 交互重设计：亮色活泼风 · 多页分步

## 设计方向（亮色 · 活泼）

**设计令牌**（写入 `miniapp/src/app.css`，替换现有暖纸色系）：
- 底色：`#FFF9F2` 奶油白 → 带彩色装饰（角部淡色圆斑/波点背景层）
- 墨色正文：`#22283B`；次要文字 `#8A8F9E`
- 主行动色：蜜橘 `#FF6B35`（CTA 按钮、渐变 `#FF8F3F→#FF5C77`）
- 三个辩手色（高饱和区分）：sp0 紫罗兰 `#7C5CFF`、sp1 天蓝 `#3B9EFF`、sp2 翡翠绿 `#00B578`
- 点缀糖果色：柠檬黄 `#FFC53D`、粉 `#FF5C9D`；排名徽章金银铜改亮色版
- 形状：卡片圆角 20–24px、按钮/徽章全胶囊、卡片用带彩边或厚白底+柔和彩影
- 动效（纯 CSS，weapp 安全）：保留 `pop-in` 弹跳入场 + 级联延迟；新增 VS 徽章摆动（wiggle）、获胜页彩带纸屑（confetti-fall）、底部面板上滑（sheet-up）、按钮按压 `hover-class` 缩放、loading 弹跳圆点
- 签名元素：辩论消息做成彩色气泡卡（说话人色粗左边框 + 贴纸感头像），交锋时旋转星形 VS 徽章摆动入场

**交互结构（多页分步）**：
1. `pages/home` 输入页：大输入卡 + 快捷示例 chips（如「☀️想出去走走」「🌧雨天室内」「👥和朋友聚会」）+ 定位卡 + 开始按钮
2. `pages/debate` 辩论直播页：入场 loading 舞台 → 理解面板 → 出场地点 → 三轮辩论（自动跟屏导览保留）→ 底部 sticky 轮次进度条 + 动作栏；澄清/淘汰/换一批/最终投票改为**底部半屏面板**（overlay + sheet-up）
3. `pages/result` 结果页：🏆 获胜卡 + 彩带纸屑 → 偏好调整 → 中立点评 + 匹配度排名 → 「再来一次」回到首页

页面间状态用 **zustand**（冻结栈内的状态库，1 个小依赖）共享：`src/store/debate.ts` 持有 query/location/debate/awaiting/loading/error + `start()/resume()/reset()` 动作，页面只做渲染与跳转；resume 拿到终态（`candidates_ready`）后 `Taro.redirectTo` 结果页。后端请求格式（start/resume 的 body、消除/投票/澄清 action）完全不变。

## 应用 skill

设计决策遵循已安装的 frontend-design skill 工作流：主题化推导（辩论=擂台/聚会气质 → 高饱和糖果色 + 弹跳动效）、单一签名元素（星形 VS 交锋徽章 + 气泡辩手卡）、克制的动效编排（入场级联一次到位，其余保持安静）。
